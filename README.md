# offtime-log

対象を外していた時刻を `log.txt` に記録し、外していた時間を集計・異常チェックするための
個人用ツール。

目標: 1日の合計時間を4時間以下に抑える。

記録は iPhone の背面タップ（iOSショートカット）で打刻し、閲覧はホーム画面の PWA で行う。
PC では従来どおり `aggregate.py` で同じファイルを集計できる。

- 打刻の仕組み・ショートカットの作り方 → [SHORTCUTS.md](SHORTCUTS.md)
- 設計と仮決めの理由 → [DESIGN.md](DESIGN.md)

## ファイル構成

- `log.txt` — 実データ（git には入れない）。2種類の行形式が混在できる。
  - 手書き形式: 日付行＋【朝】【昼】【夜】＋「外した時刻-つけた時刻」（複数は「、」区切り）
  - 打刻形式: `2026/03/10 07:05 START` / `2026/03/10 07:40 STOP`（ショートカットが末尾に追記）
  - 並び順は問わない（集計側で日付順に並べ替える）。
- `aggregate.py` — 集計・警告チェックスクリプト（Python）。複数月対応。
  ```
  python aggregate.py                    log.txt 全体（月ごと＋複数月なら全期間通算）
  python aggregate.py other.txt          別ファイルを集計
  python aggregate.py --month 2026-02    2026年2月だけ集計
  python aggregate.py --json             JSON で出力（PWA との突き合わせ用）
  python aggregate.py --today 2026-03-08 「今日」を固定（テスト用）
  ```
- `docs/` — PWA（閲覧専用）。GitHub Pages で `https://felesrufa.github.io/offtime-log/` に配信する。
  - `index.html` 画面、`aggregate.js` 集計ロジック（aggregate.py の移植）、`sw.js` オフライン用、
    `manifest.webmanifest`、`icon-*.png`
- `tests/` — `parity.py` が Python 版と JS 版の結果一致を確認する（node が必要）。`sample_*.txt` はそのテストデータ。
- `tools/make_icons.py` — PWA アイコンを生成する（外部ライブラリ不要）。
- `test_log.txt` — 警告機能の動作確認用にわざとエラーを仕込んだテストデータ（git には入れない）。

## 作業記録

### 第2段階: 打刻と PWA

1. 打刻形式（`日時 START/STOP`）を決め、`aggregate.py` を手書き形式との混在対応にした。
   既存データ・テストデータの出力は変更前と完全一致することを確認。
2. `aggregate.py` の集計ロジックを JS に移植（`docs/aggregate.js`）し、`tests/parity.py` で
   両者の JSON が一致することを確認（実データ・テストデータ・BOM/CRLF・空ファイル・月指定）。
3. PWA（`docs/`）を実装。今日の合計と「外し中」表示、月タブ、統計、日別バー（タップで内訳）、警告一覧。
   ダーク/ライト対応、オフライン対応。スマートフォン相当の幅のブラウザで表示確認済み。
4. ショートカット3本（打刻・取り消し・記録を見る）の手順を SHORTCUTS.md に書いた。
   ※ ショートカット自体は iPhone 上で手作業で作る必要がある（.shortcut ファイルは署名が要るため配布できない）。

### 第1段階: 集計スクリプト

1. `log.txt` の形式を確認（日付＋【朝】【昼】【夜】＋外した-つけたのペア）。
2. 集計・警告の仕様を決めた（詳細は下記「仕様メモ」）。
3. `aggregate.py` を実装し、実データで動作確認した。
4. `test_log.txt` を作ってわざと全種類のエラーを仕込み、警告が
   正しく全部出ることを確認済み（想定した全カテゴリ検出成功）。
5. 複数月対応・見た目の改善・`--month` 絞り込みを追加（詳細は下記）。
   複数月のテストデータで、通算と各月合計の整合性・月をまたいだ
   日付飛び検出・エラー系（不正な --month・存在しない月）も確認済み。

## 仕様メモ（忘れそうな決め事）

- 「1回」＝【朝】【昼】【夜】の1区分。区分内の時間は複数ペアの合計
  （つけていた間の時間は含まない）。最長・最短も区分単位。
- 打刻形式の区分は **外した時刻** で決める: 11:00 より前=朝、16:00 より前=昼、それ以降=夜。
- 打刻は START→STOP の順に組にする。同じ分の START→STOP（0分）は打ち直しとみなして無視。
  日付をまたいだら 24:00 で分割。今日の START に STOP がなければ警告ではなく「外し中」。
- 月平均時間の分母は「記録がある日数」（暦日数の31ではない）。
- 昼の記録漏れ警告は **土日のみ**。平日の昼欠けは正常（昼食を取らないだけ）
  なので警告しない。祝日は判定していない。今日（記録途中の日）は区分欠けを見ない。
- 日付の飛び判定は、日付順に並べ替えたあとの隣接する日の差が1日でないところを見る。
  同じ日付が2回あれば「重複日付」（手書きと打刻が同じ日なら合算したうえで出す）。
- 出力はCSV/Excelではなく、PowerShellの画面にそのまま表示する形式（`--json` で JSON も出せる）。
- （仕様書にはなかったが自分の判断で追加した警告）
  - カレンダー上存在しない日付（例: 2/30）
  - 認識できない行（フォーマットに合わない行）
  - 打刻不整合（START が2回続く、STOP の前に START がない、2日以上離れている）
  - 不要なら消してもいい機能。
- 月ごとに集計し、複数月あるときだけ「全期間 通算」を先頭に表示
  （1ヶ月分しかないときは通算セクションは出さない＝重複を避ける）。
- 日付が特定できない警告（存在しないカレンダー日・日付行の前の解析不能行）は
  「月に紐づかない警告」として別枠表示。`--month` 指定時は非表示。
- 日ごとの内訳には4時間(240分)を基準にしたバーを表示。色は使わず、
  100%超過時は "⚠" マークのみで示す（PowerShellでの色化けを避けるため）。PWA では赤で示す。
- `--month YYYY-MM` で単月に絞り込み可能。存在しない月や形式違反はエラー終了。
- 集計ロジックの正本は `aggregate.py`。直したら `docs/aggregate.js` も直し、`python tests/parity.py` を回す。
