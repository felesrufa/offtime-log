# retainer-log

歯科矯正の保定期間中、マウスピースを外していた時刻を `log.txt` に記録し、
`aggregate.py` で集計・異常チェックするための個人プロジェクト。

目標: 1日の合計装着解除時間を4時間以下に抑える。

## ファイル構成

- `log.txt` — 実データ。日付ごとに【朝】【昼】【夜】の区分で
  「外した時刻-つけた時刻」を記録（1区分に複数ペア可、「、」区切り）。
  新しい日付が上に来る降順。
- `aggregate.py` — 集計・警告チェックスクリプト（Python）。複数月対応。
  PowerShellの画面にそのまま表示する想定。
  ```
  python aggregate.py                    log.txt 全体（月ごと＋複数月なら全期間通算）
  python aggregate.py other.txt          別ファイルを集計
  python aggregate.py --month 2026-02    2026年2月だけ集計
  python aggregate.py other.txt -m 2026-02
  ```
- `test_log.txt` — 警告機能の動作確認用にわざとエラーを仕込んだテストデータ。
  `log.txt` には影響しない。消してもいい。

## 仕様メモ（忘れそうな決め事）

- 「1回」＝【朝】【昼】【夜】の1区分。区分内の時間は複数ペアの合計
  （つけていた間の時間は含まない）。最長・最短も区分単位。
- 月平均時間の分母は「記録がある日数」（暦日数の31ではない）。
- 昼の記録漏れ警告は **土日のみ**。平日の昼欠けは正常（昼食を取らないだけ）
  なので警告しない。祝日は判定していない（土日だけ見ている。祝日に昼を
  食べても警告が出ないだけで実害なしと判断し、後回しにした）。
- 日付の飛び判定は「連続する行の日付差が1日でないところ」を見る
  （ファイルが新しい日付から降順に並んでいる前提）。
- 出力はCSV/Excelではなく、PowerShellの画面にそのまま表示する形式。
- （仕様書にはなかったが自分の判断で追加した警告）
  - カレンダー上存在しない日付（例: 2/30）
  - 認識できない行（フォーマットに合わない行）
  - 不要なら消してもいい機能。
- 月ごとに集計し、複数月あるときだけ「全期間 通算」を先頭に表示
  （1ヶ月分しかないときは通算セクションは出さない＝重複を避ける）。
- 日付が特定できない警告（存在しないカレンダー日・日付行の前の解析不能行）は
  「月に紐づかない警告」として別枠表示。`--month` 指定時は非表示。
- 日ごとの内訳には4時間(240分)を基準にしたバーを表示。色は使わず、
  100%超過時は "⚠" マークのみで示す（PowerShellでの色化けを避けるため）。
- `--month YYYY-MM` で単月に絞り込み可能。存在しない月や形式違反はエラー終了。
